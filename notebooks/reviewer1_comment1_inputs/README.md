# Reviewer 1, Comment 1: observed surface-balance input

`spaulding_table_s4.csv` is a normalized snapshot of Table S4 from the USAP-DC
dataset **GPS Ice Flow Measurements, Allan Hills, Antarctica**, DOI
`10.7265/N5NS0RSX`. It was retrieved from the repository's CSV preview on
31 October 2026:

<https://www.usap-dc.org/preview/dataset/nsidc/nsidc0507_kurbatov_V01/TableS4.csv>

The source paper is Spaulding et al. (2012), *Ice motion and mass balance at
the Allan Hills blue-ice area, Antarctica, with implications for paleoclimate
reconstructions*, DOI `10.3189/2012JoG11J176`.

The snapshot retains all 58 rows with coordinates. The paper reports surface
balance for the 25 ice/firn poles with surface density at least 0.8 Mg m^-3.
The 30 finite snow-plain values (surface density 0.4 Mg m^-3) are retained for
auditability but are not treated as equivalent observations because the paper
omits them owing to large density and accumulation uncertainties. Three base
stations have no surface-balance value.

Snapshot SHA-256:
`6b206e2b0c86975b0bc4f8349e963e1f6cd30336d9a45e24bfc7fb113706a7c0`.

## Regional geometry snapshot

horizontal nodes of the saved 800 m parent model. It is generated by
`../export_reviewer1_comment1_geometry.py` using bilinear resampling at 0.01 of
the source resolution, followed by the same legacy thickness correction and
nearest-node assignment as the original model runner.
